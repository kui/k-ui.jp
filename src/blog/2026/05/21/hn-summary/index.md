Hacker News の情報は読んでて飽きないのである程度速報性を担保したうえで自動で要約してフィードリーダで読むための仕組みを作った。

- https://hn-summary.k-ui.jp

類似サービスは一日をまとめて更新とかしか見つけられなかったので作った。でもどうしてもAI呼び出しにお金かかるしこれよりうまくやってるやつを見つけたら閉じる。

かなり Claude Code に任せてプランを立ててコードを書いたが、設計においてはまだ手放しには任せられない感じだった。プロンプトが良くない可能性もある。

Vibeコーディングというやつをやってみようと思ってたがDBスキーマとかが関わってくると気軽にやる気持ちにもなれず結局、生成コードをすべてレビューしながら作ることになった。

bypass permission と WSL は相性が良いが、リモートリポジトリ壊す可能性はあるから [destructive_command_guard](https://github.com/Dicklesworthstone/destructive_command_guard) みたいなのは仕込んだほうがよい。
